# Breast cancer mortality vs. temperature

The data represent the relationship between mean annual temperature and
breast cancer mortality rate.

## Usage

``` r
neoplasms
```

## Format

A data frame with 16 rows and 2 variables:

- Temp:

  Temperature in degrees Fahrenheit.

- Mortality:

  Mortality rate presented as an index.

## Source

Applications, Basics and Computing of Exploratory Data Analysis, P.F.
Velleman and D.C. Hoaglin, 1981. (page 127)
