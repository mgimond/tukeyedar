# Legacy temperature normals for Waterville Maine (1981-2010)

NOAA/NCEI derived normal daily temperatures for the city of Waterville,
Maine (USA) for the 1981 to 2010 period. Units are in degrees
Fahrenheit.

## Usage

``` r
wat95
```

## Format

A data frame with 365 rows and 5 variables:

- date:

  Date centered on the 1981-2010 period. Note that the year is purely
  symbolic.

- doy:

  Day of year

- min:

  Typical minimum temperature for the 1981-2010 period.

- avg:

  Typical average temperature for the 1981-2010 period.

- max:

  Typical maximum temperature for the 1981-2010 period.

## Source

https://www.ncei.noaa.gov/
