# Infant mortality dataset

Infant mortality dataset pulled from Table 6-2 of "Understanding Robust
and Exploratory Data Analysis".

## Usage

``` r
data(inf_mort)
```

## Format

A data frame with the following variables:

- region:

  Regional effect

- edu:

  Father's education effect

  - `ed8`: Less than High School Graduate

  - `ed12`: High School Graduate

  - `ed13to15`: Some College or Associate’s Degree

  - `ed16`: Bachelor’s Degree or Greater

- perc:

  Numbers of infant deaths per 1000 live births

## References

- Emerson, John D., and David C. Hoaglin. (1983). Understanding Robust
  and Exploratory Data Analysis. John Wiley & Sons.
