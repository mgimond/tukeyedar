# Andrew Siegel's pathological 9-point dataset

A synthetic dataset created to test the robustness of fitted lines.
Originally published by Andrew Siegel and later adapted in Hoaglin et
al.'s book.

## Usage

``` r
nine_point
```

## Format

A data frame with 9 rows and 2 variables:

- X:

  X values

- Y:

  Y values

## Source

Robust regression using repeated medians, Andrew F. Siegel, Biometrika,
vol 69, n 1, 1982.

Understanding robust and exploratory data analysis, by D.C. Hoaglin, F.
Mosteller and J.W. Tukey. 1983 (page 139)
